Site Health · Quality Contract

Measure the publication, not just the content.

RESONANCE treats the website itself as a verifiable system: structure is checked before release, browser experience and UI geometry are measured in CI, and the deployed GitHub Pages site is measured again after publication.

Four layers

Build → Geometry → Browser → Live Different checks answer different questions.

RESONANCE Site Health v0.2

1. Publication Contract

The deterministic publication contract builds the journal and checks canonical URLs, structured data, multilingual metadata, sitemap coverage, Market OS evidence boundaries and other release invariants before deployment.

2. UI & Media Contract

Geometry is treated as a release property. New images and controls must satisfy explicit markup rules before the browser audit even starts, and rendered Lighthouse audits re-check the result afterwards.

3. Experience Contract

Pull requests that change the publication run Lighthouse against a local build. Representative pages are measured on mobile, with key pages also measured on desktop. The UI Geometry Contract separately records target size, image dimensions, aspect ratio, responsive sizing, contrast and viewport checks.

4. Live Experience Audit

After a successful GitHub Pages deployment, Lighthouse measures the public site again. UI geometry is re-checked against the deployed pages, and the result is stored as an immutable workflow artifact with the audited commit/run context.

Next: multilingual visual regression

Category scores cannot reliably tell us that a Russian headline wrapped into an ugly extra line, Chinese copy clipped a control, or a media block overflowed its column. The next layer will use stable screenshots around three reference viewports: approximately 390 × 844 phone, 768 × 1024 tablet and 1440 × 900 desktop.

Evidence produced

Readable summaries

Compact Lighthouse, UI Geometry and UI Markup results are written into GitHub Actions and the PR conversation.

Raw reports

JSON and HTML Lighthouse reports plus machine-readable geometry/markup summaries are retained as workflow artifacts.

Versioned rules

Performance, accessibility, image and control requirements live in the repository rather than in tribal memory.

What the numbers do not prove

Lighthouse and UI geometry checks are controlled lab evidence. A high score does not prove Google ranking, real-user Core Web Vitals, conversion, visual taste, or identical rendering on every device and network. Those claims require their own evidence.
