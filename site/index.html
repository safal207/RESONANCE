Verified Report #016 · Idempotency state durability

The key survived. The memory didn’t.

A remote effect survived a real container restart, but process-local dedupe memory did not. Replaying the same idempotency key then created two effects. Persisting the dedupe record — or reconciling authoritative remote state before replay — preserved one effect. Score: 10/10.
