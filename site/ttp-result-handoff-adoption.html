Result Handoff / Stale Work Adoption

A stale executor may finish useful data. Only current authority may adopt that data into a consequential transition.

Rule

producer provenance + artifact digest + current adopter epoch → consequence

The boundary

A produces D→A loses authority→B adopts D→B commits
I51

Stale executor may produce data; only current authority may adopt the consequence.

I52

Handoff binds artifact digest + producer epoch + current adopter epoch.

I53

Adoption is a new authority transition, not retroactive producer authority.

I54

The consequential commit presents the current adopter fencing token.

Canonical path

AUTHORIZE PRODUCER
↓
RUN WORK
↓
OWNERSHIP CHANGES
↓
STORE ARTIFACT + DIGEST + PRODUCER PROVENANCE
↓
NO EXTERNAL EFFECT
↓
CURRENT OWNER ADOPTS EXACT ARTIFACT
↓
COMMIT WITH CURRENT FENCE
↓
RESOURCE FENCE CHECK
↓
PROVE PRODUCER → ADOPTION → EFFECT

Proof fields

Preserve artifact digest, producer identity/fence/version, production time, adopter identity/fence/version, adoption precondition/result, adoption ID/version, resource-side fence decision and final effect identity/status.
