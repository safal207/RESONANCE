Inspect the real-source replay and what it does not prove

Five queries share one saved observation of one GitHub Actions check. The endpoint returned eight checks; this demonstration deliberately projects one named run. The source is the project owner's repository, not an independent customer deployment.

The check result is historical evidence for the specified run and commit. We do not infer the branch's required checks, trust policy, current release readiness, artifact authenticity, or source completeness. Event time is not the time this local journal received the observation.

The synthetic withdrawal scenario is not a GitHub incident. No third-party bug, revenue, independent review, emotional ability, or superiority of an LLM protocol has been measured.
