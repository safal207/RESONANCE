TTP Rule · I51–I54

Result Handoff / Stale Work Salvage

Preserve useful stale-worker output as immutable data, but require explicit adoption by the current authority before any consequential commit.

Canonical path

A / fence N produces D→READY / inert→B / N+1 verifies + adopts D→B commits

I51

Stale executor may produce data; only current authority may adopt the consequence.

I52

READY artifact is data, not commit authority. READY must not imply APPROVED or PUBLISHABLE.

I53

Adoption binds exact artifact identity and authority epochs. Bind digest, producer identity/fence/version, current adopter identity/fence/version, lease validity and adoption state.

I54

Consequential commit uses the adopter's current fencing token. Useful producer provenance is preserved; stale producer execution authority is not.

Proof

Preserve artifact ID/digest, producer epoch, READY state, adopter epoch, adoption precondition/result, resource-side fence decision and final effect identity.

Producer provenance crosses the handoff. Producer authority does not.

Boundary

This experimental rule is derived from a deterministic PostgreSQL + local HTTP benchmark. It is not a universal artifact protocol, exactly-once guarantee or production certification.
